# plugin

Manage plugins.

```sh
slidesk plugin search steps
slidesk plugin install @gouz/steps
slidesk plugin install https://github.com/someone/my-plugin.git
slidesk plugin update @gouz/steps
slidesk plugin remove @gouz/steps
slidesk plugin push my-plugin
```

An addon installs from the hub (`@user/name`) or from its git repository: see [Install from a git repository](../../how-to/manage-addons.md#install-from-a-git-repository).
