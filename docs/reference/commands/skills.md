# skills

Add AI skills to help you write your presentations.

```sh
slidesk skills
```

This command fetches the latest [SliDesk skill](https://raw.githubusercontent.com/slidesk/slidesk/refs/heads/main/SKILL.md) and [SliDesk Link skill](https://raw.githubusercontent.com/slidesk/slidesk.link/refs/heads/main/mcp/SKILL.md) from GitHub and installs them as `.claude/skills/slidesk/SKILL.md` and `.claude/skills/slidesk-addons/SKILL.md`, where Claude Code looks for project skills.

Once installed, Claude Code and other compatible AI tools can use these skills to better understand SliDesk syntax, configuration, and CLI usage when assisting you with your presentations.
