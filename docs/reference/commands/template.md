# template

Manage templates.

```sh
slidesk template search split
slidesk template install @gouz/split
slidesk template install https://github.com/someone/my-template.git
slidesk template update @gouz/split
slidesk template remove @gouz/split
slidesk template push my-template
```

An addon installs from the hub (`@user/name`) or from its git repository: see [Install from a git repository](../../how-to/manage-addons.md#install-from-a-git-repository).
