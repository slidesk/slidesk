# theme

Manage themes.

```sh
slidesk theme search dark
slidesk theme install @gouz/night
slidesk theme install https://github.com/someone/my-theme.git
slidesk theme update @gouz/night
slidesk theme remove @gouz/night
slidesk theme push my-theme
```

An addon installs from the hub (`@user/name`) or from its git repository: see [Install from a git repository](../../how-to/manage-addons.md#install-from-a-git-repository).
